# Data

| File | What it is |
|---|---|
| `alexa_data.csv` | Training set: 5,700 unique commands across 29 intents (200 each, 100 for `memory`). Generated by `scripts/build_dataset.py`. |
| `heldout_utterances.csv` | 90 hand-written commands (3 per intent, plus 3 for Word export), phrased differently from the training templates. Excluded from generation and never used for training. |
| `sample_intents.csv` | Tiny synthetic set in the *original* leaky format (row numbers appended), used by tests to check the leakage clean-up. |

## How `alexa_data.csv` is built

`scripts/build_dataset.py` holds 10–20 phrasings per intent with slots such as `{city}`,
`{time}`, `{item}`, `{artist}` or `{dest}`. Each sentence is filled with random slot values,
optionally wrapped in spoken fillers ("hey alexa", "can you", "please", "um"), and kept only
if it is new. Calculator and unit-conversion rows get random numbers and unit pairs.
Any sentence that matches the held-out file is skipped.

```bash
python scripts/build_dataset.py --per-intent 200 --seed 7
```

Because train and test sentences come from the same templates, a random split of this
data still scores close to 100%. The held-out file, written separately by hand, is the
honest measure of how the model handles new phrasing.
